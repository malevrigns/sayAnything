# sayAnything — 校园匿名聊天 UI 改版

用户已明确纠正：产品仍是校园人与人匿名聊天，长提示词只作为 UI 参考，不改成 AI 助手。保留现有 Go 业务、校园广场、房间、私聊、举报、屏蔽、资料设置。优先更新现有 Flutter Android 应用；介绍下载官网保持现有职责。

## 视觉与结构

390×844 主尺寸，360–430 适配；桌面预览同样居中最大480，取消宽屏侧栏。全灰度、深色，品牌统一 sayAnything，Lucide 线性图标，无彩色头像、机器人或插画。背景使用用户指定 CloudFront 视频，全局仅一个播放器，灰度、亮度0.45、聊天页加深遮罩；失败、关闭背景或减少动画时回退静态灰色渐变。

使用原 Flutter 工程，把 CSS 液态玻璃参考转为 ClipRRect + BackdropFilter + 渐变边缘。轻玻璃用于卡片和消息，强玻璃用于输入、底部导航、抽屉。正文16，行高1.7；标题24–28/500；字标600。英文字体Poppins，本地打包；中文用系统字体回退。

三个一级导航：聊天 / 记录 / 设置。聊天默认校园广场，房间入口打开子页面；记录为既有匿名私聊；设置保留匿名身份与现有权限设置。进入对话、搜索、隐私等子页隐藏导航；键盘打开也隐藏导航。

人际聊天不加入 AI 文案、模拟 AI 回复或停止生成按钮。输入为空禁用发送，实际网络失败保留草稿；正在发送和网络中断均灰度提示。上翻消息时不强制滚动，显示回到最新按钮。隐私文案据实说明现有服务端存储，不伪装成本地保存或服务器已删除。

新增的界面偏好仅影响UI：动态背景开关、减少动态效果、文字大小。保留当前真实会话和数据，不清空用户数据库。
