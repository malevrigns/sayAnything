# 心动匹配与资料卡（1.5）

**目标：** 对标陌陌 / 探探的核心发现闭环：资料卡 → 左右滑动 → 互相心动即配对并进入私聊。保留校园隔离、匿名身份、Go 业务权威与现有私聊、附近、屏蔽规则。

**范围（本次迭代）**

- 资料卡字段：一句话简介 `bio`（≤120 字，可空）、年级 `grade`（服务端枚举，可空）、兴趣标签 `tags`（≤5 个，只能从 Go 提供的列表中选择）。不新增真实姓名、年龄、头像上传；形象照留到下一迭代单独评估匿名性。
- `GET /api/v1/config` 新增 `profile:{bioCharacters,maxTags,tags[],grades[{id,label}]}` 与 `discover:{dailyLikes}`；客户端只用于展示与输入提示。
- `PATCH /api/v1/me` 新增 `bio` / `grade` / `tags`，事务内只合并提交字段。
- `GET /api/v1/discover?gender=` 返回最多 20 张同校、允许私聊、未屏蔽、未滑过的卡片，先排喜欢过我的人、再排资料完整者，其余按昵称稳定排序（不按活跃度，避免泄露在线情况）；响应含 `likesMe`（喜欢我且我未处理的人数）与 `likesLeft`（今日剩余心动额度）。
- `POST /api/v1/discover/{id}/swipe {action: like|pass}`：事务内校验对方可见性、屏蔽、私聊开关；同一动作重复提交为幂等回放，不重复计额度；`like` 每日上限 50（UTC 日期）；双方互相 like 时创建 `matches` 记录与普通会话，返回 `{matched:true, conversation}`。
- `GET /api/v1/discover/likes` 喜欢我且我尚未处理的人；`GET /api/v1/discover/matches` 配对列表（含会话 ID）。
- `pass` 记录 30 天后清理，让错过的人可再次出现；额度记录按日清理；删除身份级联清理滑动与配对。
- 客户端：底栏新增「心动」页（卡片堆叠、手势滑动、按钮、配对弹窗、喜欢我入口与角标、额度提示）；「我」页可编辑简介 / 年级 / 标签并在卡片中展示。

**验证：** Go 单元测试覆盖校园隔离、屏蔽、自我排除、已滑排除、互相心动建会话、幂等、额度、私聊开关、资料校验与配置一致性、删除级联；`go vet`；Flutter analyze / 测试（卡片交互、资料编辑、导航 5 栏）。
