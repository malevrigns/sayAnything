# 客户端与 Go 的职责

sayAnything 的业务数据和权限由 Go 服务负责。Flutter 是 Android、Windows 和内部 Web 预览共用的界面层，Dart 文件中的大部分代码是控件布局、交互与平台适配。

| 职责 | 所在位置 |
| --- | --- |
| 匿名身份、会话校验、校园隔离、屏蔽关系 | Go |
| 帖子、评论、房间、私聊、未读状态、幂等提交、删除事务 | Go + SQLite |
| 媒体识别、图片重新编码、额度、访问凭证、附件绑定与清理 | Go |
| 可用分类、正文长度、附件数量/大小/格式限制 | Go 的 policy.go，经 /api/v1/config 提供 |
| 聊天搜索、历史消息检索、匹配摘要、结果权限过滤 | Go + SQLite |
| 页面、输入、草稿、上传进度、文件选择、图片缩放、视频播放 | Flutter 与系统能力 |
| 字号、减少动态效果、登录凭据的设备安全存储 | 客户端 |

客户端连接或恢复身份时，先获取 Go 的配置，再进入聊天界面。客户端用这些数据展示分类、字数提示和附件限制；这些提示不构成权限或业务校验。绕过客户端直接调用 API，仍必须通过 Go 校验。更新时先部署 Go 1.3，再安装新客户端；缺少配置接口的旧服务会触发明确的升级提示。

搜索不再只筛选客户端已加载的最近会话摘要。客户端发送关键词并展示服务端结果，空输入不发请求。250ms 防抖和请求序号处理快速输入，旧请求的结果和错误都不能覆盖新关键词。Go 在当前参与者与屏蔽关系范围内搜索昵称及全部历史消息，最多返回最近 200 个匹配会话，不改动已读状态。

## 包体与职责迁移是两项工作

规则迁移减少客户端的业务耦合，后续修改分类或限制值只需发布 Go 服务。它不会消除 Flutter 引擎、字体和视频播放的本地库。

1.2 通用 APK 为 68,729,028 字节，包含 ARM64、ARMv7 和 x86_64 三套原生库，中文字体压缩后约 10.8 MiB。1.3 明确启用发布图标裁剪，并额外输出架构专用 APK。官网优先提供 ARM64，保留通用版、32 位版和模拟器版；各包使用相同版本号，避免切换架构包造成版本回退。

| 安装包 | 1.3 实测字节数 | MiB |
| --- | ---: | ---: |
| 通用兼容版 | 67,877,428 | 64.73 |
| ARM64 | 32,569,646 | 31.06 |
| ARMv7 | 30,047,810 | 28.66 |
| x86_64 | 34,027,466 | 32.45 |

ARM64 下载体积比旧通用 APK 小 52.61%，主要来自架构拆分。中文字体和媒体功能继续保留；NotoSansSC、Poppins 文件的 SHA-256 与旧包相同。实际安装包大小及哈希由 scripts/release-manifest.ps1 从发行文件生成，记录于本机 dist/release-manifest.json。
